### About Me

- I build software for clients and my own products under [Aioomi](https://aioomi.com), from the first sketch to production.
- Individual investor since 2018. I built [Podatek Giełdy](https://podatekgieldy.pl) after hours in Excel doing my own PIT-38.
- I build tools for AI coding agents and use them in my own daily work.
- I work mostly with TypeScript, React, Node.js and Python, with PostgreSQL and Supabase underneath.

### Focus Areas

- **Software architecture:** module boundaries, clean domain models, design systems kept consistent by tests rather than reviews.
- **Performance optimization:** query tuning, rendering and frame budgets, caching, bundle size, profiling before guessing.
- **Databases:** PostgreSQL schema design, migrations with rollbacks, row-level security, Supabase.
- **Integrations:** payments and refunds (Stripe, webhooks), Jira Cloud apps, e-mail delivery, OAuth, MCP servers, third-party APIs.
- **Security and privacy:** Content Security Policy and security headers, server-side validation, secrets handling, GDPR-compliant data flows.
- **Reliability:** CI pipelines, automated QA in headless browsers, regression checks, watching production after release.
- **AI engineering:** agent workflows, tool calling, evaluation, LLM features that hold up in production.

### Products

- [**Pieowl**](https://pieowl.com): simple, private product analytics you can just ask. Visitors, funnels and revenue, with answers from Claude or Cursor over MCP. No cookies, EU cloud.
- [**Podatek Giełdy**](https://podatekgieldy.pl): PIT-38 and PIT/ZG calculator for investors in Poland. Imports broker reports (IBKR, XTB, Trading 212, Revolut, Degiro), FIFO with NBP rates.
- [**Sketchbook Planning Poker**](https://marketplace.atlassian.com/apps/2267307914/sketchbook-planning-poker): real-time planning poker inside Jira Cloud that writes the agreed estimate back to the issue.

### Open Source

- [**creative-landing**](https://github.com/Krowli/creative-landing): agent skill and Claude Code plugin that builds animated, award-level landing pages with builder subagents and a headless QA loop.
- [**pagelore**](https://github.com/Krowli/pagelore): durable project memory for AI coding agents. Decisions and post-mortems as markdown in your repo, searched via CLI or MCP.
- [**kanbo**](https://github.com/Krowli/kanbo): a Kanban board your AI agents drive through a CLI and an MCP server, while you watch and approve.
- [**bug-hunter**](https://github.com/Krowli/bug-hunter): autonomous web-app bug hunter over the Chrome DevTools Protocol, as an agent skill.
- [**visual-parity**](https://github.com/Krowli/visual-parity): see the UI, don't guess. Headless screenshots diffed against the design.
- [**opencode-claude-bridge**](https://github.com/Krowli/opencode-claude-bridge): use a Claude Max subscription in OpenCode through the official Claude Agent SDK.
